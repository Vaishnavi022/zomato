## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/Vaishnavi022/zomato.git
```

2. Navigate to project folder:

```
cd zomato
```

3. Install dependencies:

```
npm install
```

4. Run the project:

```
npm start
```
